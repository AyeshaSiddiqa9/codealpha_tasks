# 🤖 Rule-Based Chatbot

## 📌 About

This project was developed as part of the **CodeAlpha Python Programming Internship**.

The chatbot interacts with users by responding to predefined questions and commands through a simple text-based conversation.

- Responds to predefined user inputs
- Handles greetings and common questions
- Exit option to end the conversation
- Beginner-friendly implementation
