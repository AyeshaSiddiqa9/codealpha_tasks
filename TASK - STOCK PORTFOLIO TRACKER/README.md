# 📈 Stock Portfolio Tracker

## 📌 About

This project was developed as part of the **CodeAlpha Python Programming Internship**.

The Stock Portfolio Tracker is a console-based Python application that allows users to select stocks, enter the quantity they wish to purchase, and calculates the total investment amount based on predefined stock prices.

---

## 🚀 Features

- Displays available stocks and prices
- Allows users to purchase multiple stocks
- Calculates total investment
- Saves portfolio details to a text file
- Simple and user-friendly console interface
