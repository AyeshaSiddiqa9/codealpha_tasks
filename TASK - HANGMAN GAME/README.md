# 🎮 Hangman Game

## 📌 About

This project was developed during the **CodeAlpha Python Programming Internship**.

Hangman is a classic word guessing game where the player tries to guess a hidden word one letter at a time before running out of attempts.

---

## 🚀 Features

- Random word selection
- Letter-by-letter guessing
- Tracks incorrect attempts
- Win/Lose detection
- User-friendly console interface

---

## 🛠 Technologies Used

- Python
- Random Module
- Strings
- Loops
- Conditional Statements
